# Create Project Plan

1. Use only permission-filtered context and the typed Planning input.
2. Call only `planning.manage_run@1` with CREATE, RESUME_INPUT, UPDATE_DRAFT, PREPARE_ACTION or EXPLAIN.
3. Planning owns adequacy: ask one goal or decisive question, otherwise draft early with explicit assumptions.
4. Relative drafts create no business rows. PREPARE_ACTION requires an exact current draft and anchor date.
5. Return validated references and stop at Manager review; never approve, apply or invent authority.
6. Return other capabilities to the Orchestrator. Failure preserves the manual editor.
